Welcome to the personal website of **Ananya Mishra**, Software Developer & B.Tech Graduate in Computer Science & Business Systems.

## 🌟 Portfolio Highlights & Unique Design

- **Obsidian Noir Aesthetic**: Built with a sleek dark obsidian backdrop (`#030305`), titanium text scales, and electric sapphire accents (`#3b82f6`).
- **Interactive Mouse Spotlight Follower**: Smooth radial gradient spotlight tracking cursor movement across the viewport.
- **Bento Grid Architecture**: Structured bento grid layout presenting education, IIT Kharagpur research experience, skill cloud, and certifications.
- **Developer Terminal Simulator**: Interactive code terminal widget with tabs for Java Backend, MERN Stack, and IIT Kharagpur data automation scripts.
- **Real GitHub Projects**: Showcases live projects directly linked to [github.com/ananyamishra2025](https://github.com/ananyamishra2025):
  - **Agro Mitra** (MERN Stack Agricultural Platform)
  - **Chat App** (Real-Time WebSockets Messaging)
  - **Trader Risk Dashboard** (Financial Market Risk Analytics)
  - **Lead Management System** (Full-Stack MySQL CRM)
- **Accessible Contact Form Validation**: Real-time validation for Name, Email, and Message with success toast alert.

## 🚀 Running Locally

1. Clone or download the repository:
   ```bash
   git clone https://github.com/ananyamishra2025/Portfolio.git
   cd Portfolio
   ```
2. Open `index.html` in your browser or run with a local server:
   ```bash
   npx serve -l 3000
   ```
